# Salpakan — Native Android

A native Kotlin + Jetpack Compose Android project using a Chess-inspired charcoal, forest-green, and gold visual theme.

## Build an APK
1. Open the **Actions** tab in this repository.
2. Select **Build Salpakan Android APK**.
3. Press **Run workflow** (or let a push trigger it).
4. Download the **Salpakan-debug-apk** artifact from the completed run.

## Current starter scope
- Native Android application (not a WebView wrapper)
- 8 × 9 board layout
- Dark/green/gold theme
- Local board interaction and rank-visibility toggle

## Important
This is the first native foundation, not a finished competitive Games of the Generals engine. Full official movement rules, army setup validation, rank-vs-rank combat, the Spy/Five-Star General attack exception, flag capture, game-end conditions, online rooms, Firebase authentication/database, and chat still need implementation and testing before public play.
